# Instructions for npm-diff.app

## Repository Overview

**npm-diff.app** is a Next.js web application for inspecting and comparing changes between npm package versions. It provides a visual diff interface with file changes, bundle size comparisons, and package metadata.

- **Stack**: Next.js 16 (App Router), TypeScript, React 19, Tailwind CSS, Turbopack
- **Package Manager**: pnpm (required — do not use npm or yarn)
- **Deployment**: Vercel (automatic on push to main)

## Build & Validation Commands

CI runs these in order — all four must pass:

```bash
pnpm run lint          # ESLint + Prettier (fix: pnpm run lint-fix)
pnpm run test-ci       # Jest tests (dev: pnpm run test)
pnpm run typecheck     # TypeScript strict mode
pnpm run build         # Next.js production build (Turbopack)
```

Other commands:

- `pnpm run dev` — dev server on `http://localhost:3000`
- `pnpm run start` — production server (requires build first)
- `pnpm run lint-staged` — pre-commit checks (ESLint + Prettier on staged files)

## Project Structure

- **`src/app/`** — App Router pages, layouts, API routes
- **`src/components/`** — Shared React components
- **`src/lib/`** — Utility libraries (API clients, diff parsing, query handling)

### Conventions

**Underscore-prefixed directories** (`_page`, `_layout`) group related components within a route directory. They are not part of the URL structure.

**API route `-` prefix**: Routes under `src/app/api/-/` use a `-` segment to avoid conflicts with the catch-all `[...parts]` route. See `src/app/api/-/README.md`.

**Import alias**: Use `^/` for imports from `src/`:

```typescript
import { something } from "^/lib/utils"; // Correct
import { something } from "../../../lib/utils"; // Avoid
```

**Generated files**: Do not commit changes to `next-env.d.ts` — it is auto-generated by Next.js.

**Test files**: Colocated with source using `.test.ts` / `.test.tsx` extensions.

**Git hooks**: Pre-commit hooks (via `simple-git-hooks`) run `pnpm run lint-staged` automatically.

## Architecture

### Diff Flow

1. User enters package specs (e.g., `react@17.0.0...react@18.0.0`)
2. `src/lib/destination/` canonicalizes specs and redirects if needed
3. `src/app/[...parts]/page.tsx` renders the diff page
4. `src/lib/npmDiff/` fetches diff using `libnpmdiff` (server-side)
5. `src/lib/gitDiff/` parses diff into React components
6. `react-diff-view` renders the visual diff

### Server vs. Client Components

Most components are Server Components by default. Add `"use client"` for interactive components. The `.client.tsx` suffix is a naming convention for when a client and non-client file share a name.
